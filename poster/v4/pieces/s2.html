Every integer carries an interval. Branches narrow it; a loop variable matches a known recurrence or becomes unknown. A proved access loses its clamp.

Branch guard

var i = data[g.x]; if (i < 8u) { … lut[i] … }
i ∈ [0, 7] in the branch

Bit mask

lut[data[g.x] & 7u]
x & 7 ∈ [0, 7]

Loop recurrence

for (var k = 128u; k > 0u; k = k >> 1u)
k ∈ [1, 128] in the body

Relation a ≥ b

if (lid >= off) { t = s[lid - off]; }
lid − off ∈ [0, 254]
Not proved, so the clamp stays: runtime-sized arrays, bounds like i < arrayLength(&a), facts across calls, guards on let values.
